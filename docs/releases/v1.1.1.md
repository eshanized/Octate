# Octate v1.1.1

**Release type:** Patch release  
**Previous release:** [v1.1.0](https://github.com/eshanized/Octate/releases/tag/v1.1.0)

Octate v1.1.1 corrects the npm-facing release presentation and makes package metadata and documentation links consistent with the published project.

## Fixes

- Replace the stale development-version banner with the current package version and direct links to the changelog and release notes.
- Point npm's **Homepage** field to the official [Octate website](https://octate.tonmoyinfrastructure.org/).
- Use absolute GitHub URLs for documentation links in the README so links work when the README is rendered on npm, where repository documentation files are not bundled into the package.
- Add a release-metadata check to the packaging verification step to detect mismatched versions, incorrect homepage URLs, missing release notes, and broken relative documentation links.
- Generalize the GitHub Release workflow so it can validate versioned release notes and explicitly dispatch npm publication, while guarding against duplicate publication.

## Verification

The release candidate is validated through GitHub Actions:

- TypeScript typecheck
- Biome lint
- Unit and integration tests
- Release metadata checks
- Build and package verification

## Installation

```bash
npm install -g @tiverse/octate@1.1.1
```

For an on-demand invocation:

```bash
npx @tiverse/octate@1.1.1 review
```

AI-backed review requires a valid `NVIDIA_API_KEY`. See the [Quickstart and configuration guide](https://github.com/eshanized/Octate#quickstart) for setup instructions.
