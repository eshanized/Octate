# Octate v1.1.0

**Release date:** 2026-10-17  
**Previous release:** [v1.0.0](https://github.com/eshanized/Octate/releases/tag/v1.0.0)

Octate v1.1.0 focuses on review correctness, repository safety, configuration predictability, and trustworthy results in interactive and automated workflows.

## Highlights

### Review the intended Git snapshot

- Corrected staged, working-tree, commit, and revision-range diff handling.
- Improved root-commit, multi-hunk, end-of-file newline, and file-mode diff behavior.
- Historical reviews now resolve source context against the reviewed revision, including cross-file imports, TypeScript path aliases, and common npm/pnpm workspace mappings.
- TUI source excerpts and diffs stay aligned with the selected review scope.

### More predictable configuration

- Configuration layers only override fields they explicitly declare.
- Invalid optional global configuration falls back to defaults with a warning.
- Explicit CLI policy options take precedence without accidentally resetting other configured review policies.
- The checked-in and generated configuration references better match the validated schema.

### Repository, cache, and cancellation hardening

- Improved linked-worktree discovery and symlink containment.
- Hardened Unicode-aware binary detection and ignore-file handling.
- Corrected cache accounting and mutation behavior, initialization serialization, configuration hashing, and project identity.
- Improved cancellation cleanup and re-review lifecycle behavior.

### More transparent results

- Skipped or failed filesystem diagnostics are surfaced as review warnings instead of being silently indistinguishable from a complete analysis.
- The latest re-review result determines the final blocking exit status.
- Corrected SARIF project metadata and documentation links.
- Removed unsupported guarantees about source privacy and false-positive rates from project documentation.

## Verification

The release candidate passed the repository's GitHub Actions checks:

- TypeScript typecheck
- Biome lint
- Unit and integration tests
- Build and distribution-package verification

## Installation

Install or upgrade with:

```bash
npm install -g @tiverse/octate@1.1.0
```

Or run with:

```bash
npx @tiverse/octate@1.1.0 review
```

Configure `NVIDIA_API_KEY` before running an AI-backed review. See the [README](https://github.com/eshanized/Octate#readme) and [configuration guide](https://github.com/eshanized/Octate/blob/main/docs/configuration.md) for setup details.
